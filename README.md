# PSE J-Lab

The Jacobian of small neural networks, in five labs: computed exactly, then checked against finite differences, every run sealed with a hash and a plain-language report.

- **Download:** <https://www.zeravatech.ca/downloads/model-tools/>, for Ubuntu and Windows, with SHA-256 checksums
